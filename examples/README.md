# examples/ — вайрфреймы дизайна

Статические HTML-наброски раскладки danchuo.world. **Память/референс, не продакшн-код.** Спецификация — в [`../docs/DESIGN.md`](../docs/DESIGN.md), требования — в [`../docs/PRD-danchuoworld.md`](../docs/PRD-danchuoworld.md).

| Файл | Что | Открыть |
|---|---|---|
| `wave01-desktop.html` | Главный борд, десктоп ≥1440px, bento 20×14 | двойной клик / в браузере |
| `wave01-mobile.html` | Мобайл <640px, одноколоночный стек + недельная полоса | двойной клик / в браузере |

Обе — **волна 01 «пиксель-персик»**. Это набросок композиции и характера (раскладка, иерархия, состояния), а не финальные пиксели: иконки-плейсхолдеры, hero и артефакты — заглушки, данные — демонстрационные.

Утверждено: композиция десктопа и мобайла (см. `~/.gstack/projects/danchuo-danchuo.world/designs/.../approved.json`).
