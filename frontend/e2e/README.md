# Визуальная регрессия (Playwright, пер-тайл)

Закрепляет вёрстку плиток борда перед релизом (PRD §12 M5) — то, что jsdom-юниты не ловят.
Снимаем **каждую плитку отдельно** (по `aria-label`), а не борд целиком: диффы локальны и не
шумят на соседях. Два вьюпорта: `desktop` (bento Full HD) и `mobile` (одноколоночный стек —
календарь в нём тот же, что в бенто: прежняя недельная полоса снята, см. DESIGN §8).

## Детерминизм

`e2e/fixtures.ts` подменяет все клиентские `/api/*` фикстурами и фиксирует часы
(`page.clock`), чтобы даты, Spotify и индикатор свежести не плавали. Картинки в фикстурах —
`null` (тайлы рисуют плейсхолдеры, без загрузок из сети). Тема инжектится SSR из реальной БД
(детерминирована).

## Эталоны снимаются в Docker

Локальный рендер шрифтов (win/mac) отличается от CI субпиксельно и плодил бы ложные диффы,
поэтому эталоны генерим в официальном Playwright-образе. Сайт должен быть поднят
(`docker compose up`).

```bash
# из frontend/
npm run e2e:docker:update   # перегенерировать эталоны (после намеренных правок вёрстки)
npm run e2e:docker          # прогнать против эталонов (как в CI)
```

Эталоны лежат в `e2e/__screenshots__/<desktop|mobile>/<tile>.png` и коммитятся в репо.

### Почему `update` переснимает **все** эталоны

`e2e:docker:update` зовёт `--update-snapshots=all`, а не голый флаг. Голый работает в режиме
`changed` — переписывает только те снимки, что не сошлись, — а сравнение у Playwright двойное:
пиксель считается разошедшимся по `threshold` (0.2 по YIQ), и лишь потом доля таких пикселей
сверяется с `maxDiffPixelRatio` (0.01). Правка, которая не добирает ни того, ни другого,
«сходится» — и эталон молча остаётся со старым рендером, хотя команду переснять уже дали.
Так пережили обновление чип вкладов в статах и целый ряд навигации в календаре: снимки
показывали борд, которого в коде уже не было. Отсюда правило: **правили вёрстку — глазами
посмотреть на переснятый PNG**, зелёный прогон сам по себе не доказывает, что эталон свежий.

## Локальный прогон (для отладки логики, НЕ для эталонов)

```bash
npx playwright install chromium   # один раз
npm run e2e                        # против host-сайта на :3000
```

Локально снятые эталоны коммитить не нужно — CI-эталон только из Docker.
