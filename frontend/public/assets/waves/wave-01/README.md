# Спрайты волны 01 «Студия / Персик»

Ассеты, сгенерированные под скин волны 01 (Recraft). Полный регламент — `docs/DESIGN.md` §12.

Два класса живут в подпапках:

- `symbols/` — символьный набор. **Волна 01 реализована инлайн-компонентом `Icon`**
  (`src/components/Icon.tsx`, стиль **line**, `currentColor`): `close`, `rotate`, `help`,
  `external`, `star`. Инлайн выбран вместо SVG-файлов+маски (лучше для ховера кнопок). Эта
  папка — задел под волны, которым понадобятся отдельные файлы/маски (напр. пиксельный набор).
- `quest/` — **цветные спрайты тропы «Сегодня»** (§4.1): `stretch`, `podcast`, `office`,
  `reading`, `journal`, `monster`, `start`, `finish`. Полноцветный пиксель-арт в палитре
  скина; НЕ красится токеном → у каждой волны своя копия.
- `decor/` — цветной фон-декор и мелочь: `rock` (камни вдоль тропы «Сегодня» — извлечён из
  референса, раскидан в `QuestMap` через `ROCKS`); `pin-start` (колесо) / `pin-finish` (клетчатый
  квадрат) — **мини-пины карты Велобайка** (§7.6), **упрощённые ручные пиксель-пины** под мелкий
  размер (~34px, optical sizing), подключены в `RideMap` через `RIDE_PINS`; `pin-*-detailed` —
  детальные Recraft-версии про запас (под будущую крупную карту); далее `peach-*` (пиксель-персики
  на фон).

Имена — kebab-case. Формат: **маска — SVG**, **цветной пиксель-спрайт — PNG** (растровый
пиксель-арт от `digital_illustration/pixel_art` + removeBackground, см. DESIGN §12.4).
Замена ассета → бампнуть `?v=` у потребителя (кэш).

Готово (волна 01): `quest/` — 8 иконок тропы (stretch, podcasts, office, reading, journal,
monster, start, finish), **извлечены из картинки-референса владельца** (crop → removeBackground
→ trim; Recraft для этого простого стиля переусложнял, см. DESIGN §12.4). Подключены в `QuestMap`
(prop `wave`, реестр `QUEST_SPRITE_WAVES`); подача D «крем + кольцо», жирные стрелки под стиль.
